# GSE17542 SN-versus-VTA result

## Main result

Nineteen of the 21 frozen human candidates mapped unambiguously to measurable
mouse genes. No candidate passed genome-wide FDR <= 0.05 in any declared SN,
VTA, interaction, or baseline-region contrast.

Neither the full panel nor any prespecified module showed significant response
magnitude or coordinated direction relative to probe-count- and residual-
variance-matched genes. This includes both primary 10-day tests:

- 10-day MPTP response in vulnerable SN dopamine neurons
- 10-day SN response relative to VTA response

The smallest nominal module result was greater baseline expression of the
retromer/endosomal module in SN than VTA (signed matched-null p = 0.0618). It is
not an exposure effect and does not survive correction across module tests.

## Interpretation

The regional-vulnerability design does not rescue the fixed panel's toxin-
response hypothesis. Nominal individual effects such as MFN1 at 2 days are
exploratory because their genome-wide FDR values are large. Final competition
tables should be confirmed with limma empirical-Bayes moderation, but the
matched-module results are sufficiently far from significance that moderation
is unlikely to reverse the overall conclusion.
